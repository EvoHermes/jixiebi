# A130 摄像头简易跟踪版

这是在现有 A130 STM32F103 固件外面增加的一个最小视觉闭环。上位机/树莓派负责摄像头和视觉，STM32 继续负责舵机、限位、速度和底层执行；烧录资料包固件前请先看文末的 J1 换算检查。

## 功能

- USB 摄像头读取画面。
- 通过 HSV 颜色分割寻找最大目标区域，默认寻找红色目标。
- 目标偏离图像中心时，逐步修改 A130 的 `x/y`；目标面积太小时逐步降低 `z`，实现“看见目标后向目标靠近”。
- 使用资料包中相同的五关节 IK 和 `0xAA ... 0xBB` 16 字节关节协议。
- 目标在中心且大小达到阈值后只保持位置，不自动闭合夹爪。
- `--dry-run` 不发串口，只打印数据帧；`--self-test` 不需要摄像头和硬件。

## 硬件假设

1. 摄像头固定在最上方夹爪附近，镜头大致朝向夹爪的接近方向，先不要让摄像头相对夹爪晃动。
2. 目标先贴一块明显的红/绿/蓝/黄色标记，背景尽量不要有同色物体。
3. STM32 的 USART3 接到 USB-TTL 或蓝牙串口，当前资料中的固件默认波特率为 `9600`。
4. 初始姿态默认是 `x=0.23, y=0, z=0.30 m`、`rx=0, ry=0`，可用 `--x0/--y0/--z0` 调整；运动方向可用 `--x-sign/--y-sign/--z-sign` 调整。

## 运行顺序

```text
python -m pip install opencv-python pyserial
python a130_visual_servo.py --self-test
python a130_visual_servo.py --port COM10 --dry-run
python a130_visual_servo.py --port COM10 --color red
```

第一次上电建议只用 `--dry-run` 看画面和发送的角度，再把机械臂架空测试。目标移动方向反了时切换对应符号，例如：

```text
--x-sign 1 --y-sign -1
```

## 当前版本的边界

- 这是“图像中心伺服”，不是完整的三维目标定位；它不会识别物体类别，也没有做相机内参、手眼标定或深度测量。
- `target-width` 是目标在画面中的期望宽度，默认 `120` 像素；需要根据摄像头分辨率和目标大小调整。
- 串口协议发送的是五个关节角，夹爪保持中立值 `0`。夹取动作应在确认目标已稳定后单独加入。
- 目标丢失时程序不继续发新位置，按 `q` 或 `Esc` 停止。

## 使用资料包固件前的检查

资料包中的 `MiniBalance_HARDWARE/USART_X/usart_x.c` 第 141 行目前是：

```c
move_angle[0] = move_angle[1] * 0.001;
```

但控制代码实际使用 `move_angle[1]` 作为 J1，因此建议改为下面这一行后重新编译烧录：

```c
move_angle[1] = move_angle[1] * 0.001f;
```

否则 J1 可能把毫弧度整数当成弧度，触发限位。Python 脚本仍按资料包协议发送六个 `int16` 毫弧度值。
